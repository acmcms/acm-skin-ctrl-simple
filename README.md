# acm-skin-ctrl-simple

A minimal, modern AxiomCMS admin control skin — four small packages (`ctrl-simple`, `ctrl-simple-form`, `ctrl-simple-browse`, `ctrl-simple-execute`), each just a `skin.settings.xml` plus one or two `.htm.tpl` templates. `ctrl-simple-form`'s `<import>` of AE3's `skin-jsclient` package (`ae3.sys.pkg.l2.tgt.dhtml`) is the confirmed evidence that AxiomCMS's `ACM.TPL` skin mechanism and AE3's own skin packages are one continuous system, not two separate ones (see `magic-axiomer`).
